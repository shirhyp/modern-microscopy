# Image Prompts for Lux the Tardigrade

Seven self-contained prompts for generating Lux's poses with a text-to-image tool (ChatGPT, DALL-E, Midjourney, or similar). Every prompt repeats the full character description from [`character-sheet.md`](character-sheet.md), so each one works on its own.

## How to use these prompts

1. Start a new chat in your image tool and paste the **Opening Prompt**.
2. Paste the pose prompts one at a time, in order, in the same chat so the drawing style stays consistent. Generate at 1024×1024.
3. Save each result with the filename shown under its heading into `docs/img/mascot/`.
4. Check that each image has a truly transparent background (not a white or checkered one). Regenerate any that don't.

## Opening Prompt

```text
I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.
```
